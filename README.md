Тесты:

- Добавление книг

test_add_new_book_valid_name_length (параметризованный)
Проверяет, что книга успешно добавляется в коллекцию, если длина имени от 1 до 40 символов. Тестируется на минимальной (1 символ) и максимальной (40 символов) длине имени.

test_add_new_book_invalid_name_length (параметризованный)
Проверяет, что книга не добавляется, если имя пустое или длиннее 40 символов.

- Установка жанра

test_set_book_genre_success (параметризованный)
Проверяет, что жанр успешно устанавливается для существующей книги с валидным жанром. Тестируется на нескольких парах книга/жанр.

test_set_book_genre_book_not_exist
Проверяет, что жанр не устанавливается для книги, которой нет в коллекции.

-Получение жанра

test_get_book_genre_returns_genre
Проверяет, что метод возвращает правильный жанр для книги, у которой жанр задан.

test_get_book_genre_returns_none
Проверяет, что метод возвращает `None` для книги, которой нет в коллекции.

- Фильтрация книг

test_get_books_with_specific_genre
Проверяет, что метод возвращает книгу при фильтрации по её жанру.

test_get_books_for_children
Проверяет, что книги с возрастным рейтингом (Ужасы, Детективы) не попадают в список книг для детей.

- Избранное

test_add_book_in_favorites
Проверяет, что книга успешно добавляется в список избранного.

test_delete_book_from_favorites
Проверяет, что книга успешно удаляется из списка избранного.

test_get_list_of_favorites_books
Проверяет, что метод возвращает список избранных книг с добавленной книгой.
